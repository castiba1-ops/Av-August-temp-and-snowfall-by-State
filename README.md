# Av-August-temp-and-snowfall-by-State
Is there a relationship between average temperature in August and snowfall per state?
# Data
This data set has a row for each if the 50 States in the United States. My explanatory variable is each state's average temperature in August, and the other variable explains each state's annual snowfall. I used linear regression to see if the variables are related
# Data cleaning process
Made sure each state's August temperature made sense and that each value was provided.
# Instructions on How to access and utilize package
Download the acastiblanco-final_project.R and CSV. Rename them, when put together. Open the script into RStudio, press on that folder and set it to work on it(working dictionary), then click source to run the data/code
